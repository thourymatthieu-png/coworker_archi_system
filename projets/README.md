# Projets

Un dossier par projet : `projets/<nom>/`.

Nouveau projet : copier le contenu de `framework/templates/` dans `projets/<nom>/`, puis lancer l'agent `architecte-systeme`. Le profil du projet (`projet.md`) déclare la cible, la chaîne d'outils et les modules actifs (`modules/README.md`) ; les scripts propres au projet vont dans `projets/<nom>/tools/`.
